# General Space Theory (GST) glossary

This glossary records the main public terms used by the GST documentation layer.

## General Space Theory

The structural mathematical framework developed by Nidhish for organizing spaces, graph navigation, carry states, digit states, and certificates in the Problem 406 formalization.

## GST

Short Lean/documentation abbreviation for **General Space Theory**. The first public mention in prose should expand the name.

## GST Graph V2

The graph/navigation presentation of General Space Theory used to explain how local arithmetic states are organized into proof paths and certificates.

## digit3

The ternary digit projection function.

Public Lean name:

```lean
GST.Arithmetic.digit3
```

## carry4

The exact carry state generated by multiplication by four in base three.

Public Lean name:

```lean
GST.Arithmetic.carry4
```

## HappyCell

A local digit/carry gate condition used by the GST navigation layer.

Public Lean name:

```lean
GST.Arithmetic.HappyCell
```

## Navigation

The existence of a GST-valid navigation witness for a number.

Public Lean name:

```lean
GST.Arithmetic.Navigation
```

## CommonTwo

A property saying that a row exists where both `4^K` and `4^(K+1)` have ternary digit `2`.

Public Lean name:

```lean
GST.FourPower.CommonTwo
```

## exponentPrefix

The low ternary prefix of an exponent below scale `3^p`.

Public Lean name:

```lean
GST.FourPower.exponentPrefix
```

## exponentTrit

The `p`-th ternary digit of an exponent.

Public Lean name:

```lean
GST.FourPower.exponentTrit
```

## CreationCertificate

A certificate that a number has the GST creation/navigation structure required by the four-power bridge.

Public Lean name:

```lean
GST.FourPower.CreationCertificate
```

## CreationMaster

The universal master proposition for the four-power creation-certificate layer.

Public Lean name:

```lean
GST.FourPower.CreationMaster
```

## Problem 406 public theorem

The reviewer-facing theorem stating that for every exponent `n ≥ 9`, the ternary expansion of `2^n` contains digit `2`.

Public Lean name:

```lean
GST.Problem406.contains_two_digit_of_nine_le
```
