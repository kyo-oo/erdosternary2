# Phase 1 Scope

Phase 1 is a presentation-layer phase.

It does not claim to simplify the internal monolith. It creates a professional route into the accepted artifact while preserving the exact proof checkpoint.

## In scope

- Clean public theorem names.
- Reviewer-facing theorem map.
- Submission guide.
- Artifact-freeze rule.
- Additive public API CI.

## Out of scope

- Direct theorem renaming inside `ErdosTernary2.lean`.
- Deleting proof-sprint history from the monolith.
- Rewriting proof bodies.
- Changing the comparator theorem statement.
